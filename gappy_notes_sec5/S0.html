0.2 About the course

The aim of this course is to provide a comprehensive introduction to concepts in algebra and calculus for year 1 Chemistry students. Below you will find the Intended Learning Outcomes (ILOs) for this course unit.

Intended Learning Outcomes

On completion of this course unit, students will be able to

  • •
    ​

    [ILO1] Use equations in implicit or parametric form including straight lines or conic sections to extract relevant information.

  • •
    ​

    [ILO2] Identify the appropriate partial fractions form and find the values of any coefficients for a rational function of a single variable.

  • •
    ​

    [ILO3] Differentiate functions and hence locate and classify stationary points for a function of a single variable.

  • •
    ​

    [ILO4] Recall and apply appropriate rules to integrate functions and use these to measure areas associated with curves or combinations of curves.

  • •
    ​

    [ILO5] Calculate sums, differences and products involving vectors and use these to solve geometrical problems.

  • •
    ​

    [ILO6] Carry out arithmetic using complex numbers and hence solve polynomial and power equations.

  • •
    ​

    [ILO7] Model chemical processes using differential equation systems and solve these systems using a variety of techniques.

0.3 How to use these notes

These notes come in two forms,

  • •
    ​

    [This version]. The “gappy notes”, which contain gaps in the exercise solutions for you to fill as we work through the material in lectures

  • •
    ​

    The complete notes, which contains all the full solutions for examples in the lectures and supplementary videos (available on Canvas once the material has been covered in lectures).

You can alter the font size and colour scheme of this HTML version using the buttons in the top-left and you can download a PDF of these notes by clicking the save button, also in the top-left. Note that, this HTML version cannot be annotated directly, if you wish to fill the notes during lectures, you should download the PDF version.

The example exercises in this document are split into three types

  • •
    ​

    [Lecture] These examples will be covered in the lecture.

  • •
    ​

    [DIY] There will be time during lectures to complete these exercises.

  • •
    ​

    [Video] These examples are covered in videos, which can be accessed via Canvas.
